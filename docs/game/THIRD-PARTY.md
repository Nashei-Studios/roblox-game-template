# Material de terceros

Algunos moldes de esta carpeta están adaptados (recortados, traducidos al español y llevados a Roblox) de plantillas de documentación de juego del proyecto Claude Code Game Studios.

- Proyecto: Claude Code Game Studios, https://github.com/Donchitos/Claude-Code-Game-Studios
- Origen: `.claude/docs/templates/` (`game-concept`, `game-pillars`, `systems-index`, `economy-model`, `test-plan`, `accessibility-requirements`)
- Licencia: MIT
- Lectura de la licencia y de las plantillas: 2026-11-12
- Qué se adaptó: `concept.md` (concepto y pilares), `systems-index.md` y `systems/_sistema.md`, `economy.md`, `qa-plan.md`, `accessibility.md`. El resto de los moldes es propio.
- Qué no se tomó: agentes, skills, hooks ni compuertas de directores (ver ADR 0068).
