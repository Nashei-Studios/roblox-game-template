# Accesibilidad

Compromiso explícito de un nivel. Molde adaptado de `accessibility-requirements` de Claude Code Game Studios (MIT, ver `THIRD-PARTY.md`), reducido al nivel básico de las Game Accessibility Guidelines.

## Preguntas que debe responder

1. ¿Qué nivel se compromete (básico, estándar)? Cada excepción al nivel básico lleva su razón.
2. ¿El texto es legible? Tamaño mínimo y contraste verificado contra WCAG AA (barra de entrega, punto 4).
3. ¿Se puede jugar sin depender solo del color o solo del sonido?
4. ¿Se puede ajustar el volumen de música y de efectos, y desactivar el sacudón de cámara y los destellos?
5. ¿Los controles se pueden reasignar o simplificar? ¿Funciona con teclado, gamepad y táctil?
6. ¿Los objetivos táctiles miden al menos 44 puntos?
