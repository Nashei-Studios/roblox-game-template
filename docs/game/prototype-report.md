# Informe del prototipo (puerta entre diseño y construcción)

Un prototipo greybox de solo el loop, de un día como máximo. Responde una pregunta: ¿es divertido? Sin esto no se compromete la construcción. Tras el veredicto "seguir" se escriben los documentos de sistemas.

## Preguntas que debe responder

1. ¿Qué se probó exactamente (qué parte del loop y con qué piezas grises)?
2. ¿Cuál era el criterio de abandono? **Debe estar escrito antes de jugar** (con la fecha), por ejemplo: "si en 5 minutos nadie repite la vuelta por gusto, se abandona".
3. ¿Quién jugó, cuánto tiempo y qué se vio (qué hicieron sin que se les pidiera, dónde se detuvieron, qué dijeron)?
4. ¿Se cumplió el criterio de abandono?
5. ¿Veredicto: seguir, cambiar (qué) o abandonar? Si se abandona, la salida es el tema nuevo (decisión 0002 del vault).
