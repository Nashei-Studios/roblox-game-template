# Core loop

Lo que el jugador va a repetir todo el rato. Roblox lo define con tres elementos: la interacción minuto a minuto, las acciones más repetidas y el motor de progresión (Creator Hub, core loops).

## Preguntas que debe responder

1. ¿Cuál es el loop en cinco verbos o menos? (por ejemplo: llenar, vaciar, sacar, vender, mejorar).
2. ¿Cuánto dura una vuelta, en segundos?
3. ¿Qué es la interacción minuto a minuto (lo que hacen las manos)?
4. ¿Qué acción se repite más y por qué no aburre al décimo minuto?
5. ¿Qué progreso es permanente tras una vuelta y cuál se pierde?
6. ¿Funciona con un jugador y cambia con cuatro? ¿Cómo?
7. ¿Cuál es el momento filmable del loop (el que un desconocido compartiría)?
